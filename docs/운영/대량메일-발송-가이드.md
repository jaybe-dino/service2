# 대량 메일 발송 운영 가이드

Glovek 아웃리치(`/admin/oc`) 기준 운영 규율. 도구가 자동으로 막아주는 것과 사람이 지켜야 하는 것을 구분해 정리한다.
(최종 갱신: 2026-09-07)

---

## 0. 한 장 요약 — 하루 운영 루틴

1. `/admin/oc` 대시보드에서 **어제 성과·반송률·발신함 상태** 확인
2. 회신함 **[최근 30일 동기화]** → **[신규 회신 초안 일괄 생성]** → 초안 검토·발송
3. 신규 캠페인은 **스팸 점검 "주의" 이하** + **본인 메일 테스트 발송(스팸함 확인)** 후에만 생성
4. 발송 배치 실행 — 워밍업/한도는 시스템이 자동 통제
5. 반송·수신거부 숫자에 이상 징후 있으면 발송 중단하고 원인 확인

---

## 1. 발송 전 1회 세팅 (신규 도메인·계정)

| 항목 | 기준 | 확인 방법 |
|---|---|---|
| 도메인 인증 | SPF·DKIM·DMARC 3종 모두 통과 | `/admin/oc` → DNS 점검 탭 |
| 발송 도메인 분리 | **메인 도메인(glovek.space)으로 대량발송 금지** — 발송 전용 도메인/서브도메인 사용 권장 (평판 오염 시 메인 도메인 보호) | 도메인 구매 후 DWD 재설정 |
| Workspace 결제 상태 | **평가판=500통/일, 정식=2,000통/일.** 대량발송 전 정식 전환 | Google 관리 콘솔 → 결제 |
| 계정 나이 | **생성 후 2주 미만 계정은 구글이 수십 통 수준으로 스로틀.** 새 계정은 일반 메일을 먼저 주고받으며 숙성 | — |
| 수신거부 | List-Unsubscribe 헤더·링크 자동 삽입됨 (Gmail/Yahoo 필수요건) | 시스템 자동 — 별도 작업 없음 |

## 2. 계정·한도 정책

**구글이 정하는 한도 (우리가 못 늘림):**
- 정식 Workspace 2,000통/일 · 평가판 500통/일 · 신규 계정 수십~수백 통
- 한도 도달 시 24시간 후 자동 회복. 시스템이 미발송분을 큐에 유지하므로 다음 날 [발송]만 다시 누르면 됨

**우리 시스템 설정 규칙:**
- 신규 발신함: **daily_limit 100 이하 + 워밍업 ON** (커브: 30→40→60→80→120→160→220→300→400→500, 10일)
- 숙성된 발신함(4주+, 반송률 안정): daily_limit 300~500
- 물량 확장은 **한도 상향이 아니라 발신함 추가**로: 계정 3~5개 로테이션(캠페인에서 복수 선택하면 자동 분산)
- 반송률 7일 2% 초과 시 시스템이 발신함을 **자동 일시정지** — 발신계정 탭에서 사유 확인 후, 원인 해소 전 재활성 금지. 재활성 시 워밍업 다시 ON

## 3. 리스트 품질 규칙

- 세그먼트는 **M1(실적+컨택) 우선**, 콜드풀(M3)은 워밍업 완료된 발신함으로만
- 제외목록(suppression)은 절대 우회하지 않는다 — 시스템이 발송 전 자동 스킵
- 같은 수신자에게 30일 내 중복 캠페인 금지 (제품이 달라도 피로도 누적)
- 오래된 이메일 리스트(6개월+)는 반송률 폭탄 — 소량(50통)으로 반송률 먼저 측정 후 확장

## 4. 콘텐츠 규칙

- 발송 전 **[🛡 스팸 점검] 필수** — "위험" 등급이면 수정 전 발송 금지, "주의"는 항목 확인 후 판단
- 개인화 변수(`{{handle}}` `{{brands}}` 등) **최소 1개 필수** — 전달률에 가장 효과 큰 요소
- 링크는 본문에 **1~2개**, 단축 URL(bit.ly 등) 금지
- 제목: 50자 이내, 느낌표·대문자 남발 금지, 가짜 `Re:` 금지
- 신규 템플릿은 반드시 **테스트 발송 → 본인 Gmail 받은편지함/스팸함 도착 위치 확인** 후 캠페인 생성
- L2(AI 오프닝)는 워밍업 끝난 발신함 + 상위 타깃 캠페인에 사용 권장

## 5. 발송 운영 규칙

- 배치는 30통 단위(기본) — 시스템이 300~900ms 랜덤 간격으로 발송
- 발송 시간대: **수신자 국가 기준 평일 오전 9~11시** (US 캠페인은 한국 밤~새벽)
- 하루에 같은 발신함으로 캠페인+답장+테스트 합산량을 감안 — 구글 카운터는 전부 합산됨
- 첫 캠페인은 항상 **소량(50~100명) 파일럿** → 오픈·회신·반송 확인 → 본 발송

## 6. 지표 기준선 (이탈 시 발송 중단·점검)

| 지표 | 정상 | 경고 | 조치 |
|---|---|---|---|
| 오픈율 | 30%+ | <20% | 제목·발신함 평판 점검, 테스트 발송으로 스팸함 확인 |
| 회신율 | 3~5% | <1% | 타깃·템플릿 재검토 (개인화 강화) |
| 반송률 | <1% | 2%+ | **자동 일시정지 발동** — 리스트 품질 점검 |
| 수신거부율 | <0.3% | 0.5%+ | 타깃 미스매치 — 세그먼트 좁히기 |

## 7. 사고 대응

- **"Gmail 한도 도달"**: 정상 동작 — 미발송분 큐 유지됨. 다음 날 [발송] 재실행. 반복되면 §2 계정 상태 확인
- **발신함 자동 일시정지**: 발신계정 탭에서 사유 확인 → 리스트 정리 후 재활성 + 워밍업 ON
- **오픈율 급락(스팸함 의심)**: 즉시 발송 중단 → 테스트 발송으로 확인 → 발송량 절반 감축 + 1주 관찰
- **DMARC 리포트에 인증 실패**: DNS 점검 탭 재확인, DWD scope 재승인

## 8. (참고) Instagram DM 채널

현재 시스템은 이메일 전용. kb 데이터에 인스타그램 핸들 보유 크리에이터가 다수 있어 DM 채널 확장 여지는 있으나, IG DM은 **비공식 자동화가 계정 정지 위험이 높아** 공식 API(비즈니스 계정 간 제약 큼) 또는 수동 운영만 권장. 도입 검토 시 별도 기획 필요.
