# 크리에이터 아웃리치(이메일 대량 제안) — 셋업 가이드

관리자 전용 · 접근 URL: **`/admin/oc`** (기존 관리자 메뉴에는 노출되지 않음. 로그인 후 직접 URL 접속)

## 전체 흐름
1. **데이터** — 크리에이터 CSV 업로드(브라우저 파싱 → 500행 단위 적재, handle 기준 업서트)
2. **제품·컨셉** — 제품명/브랜드/카테고리/컨셉/USP 등록
3. **크리에이터 필터** — 규모(평균 조회수)·총조회수·영상수·브랜드 이력(카테고리)·지역·이메일 보유로 대상 필터
4. **발송(캠페인)** — 제품 + 발신계정 + 제목/본문(변수) + 필터 → 캠페인 생성(수신자 확정) → 배치 발송
5. **발송이력** — 수신자별 상태(sent/failed/queued/skipped)·오류·발송시각
6. **발신계정** — 등록된 Gmail 발신계정(allow-list) 관리

> 데이터 특성: 이 데이터셋은 **followers 값이 없어**, 규모 판단은 **평균 조회수(avg_views)** 로 합니다. `brands`(K뷰티 브랜드 이력)는 카테고리/관심 시그널로 필터에 사용합니다.

## 발신계정 등록 (핵심)
발송은 **등록된 발신계정으로만** 가능합니다. 시크릿(비밀번호/토큰)은 **DB에 저장하지 않고** 환경변수로 관리하며, 발신계정 레코드는 `env_key`(대문자 슬러그)로 환경변수를 참조합니다.

### 방법 A — SMTP(앱 비밀번호) · 가장 간편
1. Google 계정(기업 Gmail)에서 **2단계 인증** 활성화
2. **앱 비밀번호** 생성 (Google 계정 → 보안 → 앱 비밀번호) → 16자리 발급
3. Vercel 환경변수에 추가: `OC_SMTP_PASS_<ENV_KEY>` = 발급받은 앱 비밀번호
   - 로그인 계정이 발신 이메일과 다르면 `OC_SMTP_USER_<ENV_KEY>` 도 지정
4. `/admin/oc` → 발신계정 → 등록: 이메일, backend=SMTP, env_key=`<ENV_KEY>`
5. [테스트] 버튼으로 본인 이메일에 테스트 발송 확인

예) env_key=`PARTNERS` → 환경변수 `OC_SMTP_PASS_PARTNERS`

> Google Workspace 관리자가 앱 비밀번호를 막아둔 경우 방법 B를 사용하세요.

### 방법 B — Gmail API(OAuth2) · 견고, Workspace 권장
1. Google Cloud Console → 프로젝트 생성 → **Gmail API 사용 설정**
2. OAuth 동의 화면 구성 → **OAuth 클라이언트 ID(웹)** 발급 → client_id / client_secret
3. 발신 계정으로 **refresh token** 발급 (scope: `https://www.googleapis.com/auth/gmail.send`)
   - OAuth Playground 또는 자체 동의 플로우로 1회 발급
4. Vercel 환경변수:
   - 공용: `GOOGLE_OAUTH_CLIENT_ID`, `GOOGLE_OAUTH_CLIENT_SECRET`
   - 계정별: `OC_GMAIL_REFRESH_<ENV_KEY>` = refresh token
5. `/admin/oc` → 발신계정 → 등록: backend=Gmail API, env_key=`<ENV_KEY>` → [테스트]

## 발송 정책 / 한도
- 발신계정별 **일일 한도(daily_limit)** 를 두고, 오늘(KST) 발송량을 차감해 남은 만큼만 발송합니다.
- 1회 [발송] 클릭 시 30건 단위 배치로 반복 발송하며 남은 큐가 없거나 일일 한도 소진 시 중단합니다.
- 완만한 발송(건당 ~0.35초 간격)으로 스팸/스로틀을 완화합니다.
- **드라이런**: 실제 발송 없이 수신자·문구를 기록만 하여 사전 점검할 수 있습니다.
- Gmail 발송 한도(참고): 일반 계정 ~500/일, Workspace ~2,000/일. daily_limit을 이보다 낮게 설정하세요.

## 템플릿 변수
제목/본문에서 사용: `{{handle}} {{views}} {{avg_views}} {{total_views}} {{videos}} {{brands}} {{region}} {{profile_url}} {{product}} {{brand}} {{category}} {{concept}} {{usp}}`

## 데이터/보안 메모
- 크리에이터 CSV(약 9.5MB)는 **repo에 커밋하지 않습니다.** 관리자 화면에서 업로드로 적재합니다.
- 발신 시크릿은 DB/코드에 저장하지 않고 Vercel 환경변수에만 둡니다.
- 표 스키마: `oc_creators / oc_products / oc_senders / oc_campaigns / oc_messages` (db.ts `ensureSchema`에서 자동 생성).

## 향후(브랜드사 오픈)
현재는 관리자 전용입니다. 추후 브랜드사에게 열 경우, 발신계정·수신 대상·발송 한도를 브랜드(owner) 단위로 스코프하도록 `oc_*` 테이블에 owner 컬럼을 추가해 확장할 수 있습니다.
