# 크리에이터 이메일 DB — 지속 발굴 전략

아웃리치는 결국 **얼마나 많은 정확한 크리에이터 이메일을 확보하느냐**가 성패를 가릅니다.
한 번 산 CSV는 시간이 지나면 노후화(이메일 변경·계정 폐쇄)되므로, **지속적으로 새 DB를 채우는 파이프라인**이 필요합니다.

## 1) 우리 데이터에서 자동 확장 (비용 0, 최우선)
- **발송 성과 역이용**: 회신·오픈한 크리에이터는 "살아있는" 우량 리드 → 별도 우선 세그먼트로 관리
- **회신 서명/본문 파싱**: 회신 메일 본문에서 다른 담당자 이메일·매니지먼트 연락처 자동 추출 → DB 추가 (회신함 body_text 활용)
- **소개(referral)**: "혹시 함께할 다른 크리에이터가 있나요?" 문구로 소개 요청 → 자연 확장

## 2) TikTok 자체 수집 (핵심 소스)
- **해시태그·사운드·챌린지 크롤**: 카테고리 키워드(#kbeauty #skincare 등)로 최신 영상 → 작성자 프로필 → bio의 공개 이메일 추출
- **경쟁 브랜드 어필리에이트**: 특정 K뷰티 브랜드 태그·멘션 단 크리에이터 = 이미 뷰티 협업 의향 있는 사람 (지금 brands 필드가 이 시그널)
- **TikTok Creator Marketplace(공식)**: 브랜드 계정으로 접근 시 카테고리·지역·규모별 크리에이터 목록 열람 가능
- **주기적 재수집**: 이미 가진 핸들을 월 1회 재방문해 이메일 신규 확보/갱신 (bio 업데이트 반영)

## 3) 크로스 플랫폼 (동일인 연결)
- TikTok bio에 링크된 **Instagram/YouTube/링크트리** → 그쪽 공개 비즈니스 이메일 확보(대개 링크트리에 이메일 노출)
- Instagram "이메일 보내기" 비즈니스 버튼, YouTube 채널 "정보" 탭 비즈니스 문의 이메일

## 4) 외부 소스 (보강용)
- **인플루언서 마켓플레이스/DB 서비스**: 카테고리·지역 필터로 이메일 포함 리스트 구매(품질 편차 주의 → 검증 필수)
- **뷰티 커뮤니티·UGC 캠페인 지원자**: 우리가 직접 모집 랜딩("크리에이터 지원") 운영 → 자발적 이메일 수집(동의 기반, 법적으로 가장 안전)

## 5) 자동화 파이프라인 (권장 구축)
현재 구조에 이어 붙이기 좋은 순서:
1. **정기 크롤 잡(크론)**: 카테고리 해시태그 → 신규 핸들 → 프로필 이메일 추출 → `oc_creators` 업서트 (handle 기준 자동 병합, 이미 구현된 업서트 재사용)
2. **이메일 검증(verification)**: 새로 수집한 이메일은 발송 전 **문법·MX·바운스 위험** 체크 → 나쁜 주소는 바로 제외목록
3. **품질 점수화**: avg_views·영상수·브랜드 이력·최근 활동으로 리드 스코어 → 우선순위 발송
4. **소진 방지**: "이미 접촉/회신" 전역 제외로 같은 사람 반복 발송 방지(중복방지 필요)

## 6) 법적·평판 안전 (필수 병행)
- 광고성 메일: 제목 `[광고]` + 무료 수신거부(정보통신망법). 크리에이터 공개 **비즈니스** 이메일이라도 원칙 준수 권장
- 수집 이메일은 **공개된 비즈니스 연락처**만 사용, 개인 사생활 목적 수집 지양
- 수신거부·바운스는 즉시 영구 제외(이미 자동화됨) → 도메인 평판 보호

---

### 지금 바로 가능한 최소 실행안
1. 회신함 body에서 **연락처 자동 추출** → DB 확장 (다음 개발로 추가 가능)
2. **월 1회 해시태그 재크롤 크론** → `oc_creators` 자동 증분 (Apify 등, 단 비용 상한 설정 필수)
3. **크리에이터 지원 랜딩** 개설 → 동의 기반 이메일 유입(가장 안전·저비용)

원하시면 위 1·2·3을 개발 항목으로 잡아 순차 구축하겠습니다.
