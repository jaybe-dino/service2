# 제품 수집(틱톡샵 크롤링) 고도화 런북 — 이미지·커버리지 늘리기

> 목적: "제품이 부족하다 / 이미지가 없다"를 **직접 해결**하는 단계별 절차.
> 원인: 상품·이미지의 원천은 **Apify actor**이고, 강도·국가·상한은 **환경변수**로 정해짐.
> 소요: 최초 셋업 20~30분. 이후는 크론이 자동.

---

## 큰 그림 (왜 이 순서인가)
```
① Apify actor 준비   → 상품·이미지를 실제로 긁어오는 크롤러
② Vercel 환경변수    → 어떤 actor로 · 몇 개 · 어느 국가를 긁을지
③ 수집 실행/확인     → 크론 자동 + 어드민 버튼 + 심층크롤
```
셋 중 하나라도 비면 제품이 안 채워집니다. 지금 부족한 건 보통 ①(actor가 이미지 안 줌) 또는 ②(상한이 낮음/국가 적음).

---

## ① Apify actor 준비

1. **apify.com** 로그인 (없으면 가입).
2. **API 토큰 복사**: 우상단 프로필 → **Settings → Integrations → Personal API tokens** → 토큰 **Copy**. → 이게 `SCRAPER_API_KEY`.
3. **틱톡샵 크롤러 고르기**: 상단 **Store** → 검색 `tiktok shop`.
   - 고를 때 체크: **product image(cover) · sold count · commission**을 반환하는지(설명/예시 output 확인).
   - 추천 유형: "TikTok Shop Product Scraper" 계열(키워드/카테고리로 상품 검색).
4. **actor id 복사**: actor 페이지 URL이 `apify.com/USERNAME/ACTOR-NAME` → `USERNAME/ACTOR-NAME` 형태를 그대로 복사. → 이게 `SHOP_ACTOR`. (URL 통째로 붙여도 코드가 정규화함)
5. **(선택) 입력 스키마 확인**: actor 페이지 **Input** 탭에서 키 이름 확인 — 특히 검색어 키(`keyword`/`search`), 결과 상한 키(`maxItems`/`limit`), 이미지 포함 옵션, 정렬(판매순). → `SHOP_ACTOR_INPUT`에 쓸 재료.

> 코드는 검색어·상한·국가 키를 **슈퍼셋으로 자동 전달**하므로, 흔한 actor는 `SHOP_ACTOR`만 넣어도 동작함. 정확히 맞추고 싶을 때만 `SHOP_ACTOR_INPUT` 사용.

---

## ② Vercel 환경변수 설정

**Vercel → Glovek 프로젝트 → Settings → Environment Variables → Add New** 에서 아래를 등록 (Production).

| 변수 | 값(예시) | 의미 |
|---|---|---|
| `SCRAPER_API_KEY` | (Apify API 토큰) | **필수** — 크롤 인증 |
| `SHOP_ACTOR` | `USERNAME/ACTOR-NAME` | **필수** — 어떤 크롤러 |
| `SHOP_COUNTRIES` | `US,TH,VN,MY,SG` | 수집 국가(콤마) |
| `SHOP_MAX_ITEMS` | `1000` | 브랜드당 상품 확보량(기본 500) |
| `SHOP_MAX_BRANDS` | `16` | 사이클당 킥 브랜드 수(기본 8) |
| `SHOP_MAX_RUNNING` | `60` | 동시 처리 상한(기본 40) |
| `SHOP_RETRY_DAYS` | `1` | 재수집 주기(기본 3일) |
| `INGEST_SECRET` | (임의 문자열) | 웹훅 적재 보호(권장) |

**(선택) 이미지·정렬을 강제하려면** `SHOP_ACTOR_INPUT` 에 JSON을 넣음. `{{keyword}}`·`{{country}}`가 브랜드명·국가로 치환됨:
```json
{"keyword":"{{keyword}}","country":"{{country}}","maxItems":1000,"includeImages":true,"sortBy":"sales"}
```
(키 이름은 ①-5에서 확인한 actor 실제 스키마에 맞출 것)

→ 저장 후 **Deployments → 최신 배포 → Redeploy** (환경변수는 재배포해야 반영됨).

---

## ③ 수집 실행 & 확인

**자동**: 크론이 알아서 돎 — 상품 매시 정각(`/api/cron/collect-shop`), 영상 매시 30분.

**수동/즉시** (어드민 콘솔 → **브랜드 수집** 탭):
- **[틱톡샵 상품 수집]** 버튼 → 지금 바로 한 사이클 킥.
- **수집 강도** 슬라이더 → env 없이도 실시간 조정(`collect_tuning`).
- **수집 국가** 토글 → 국가 On/Off(`collect_regions`).
- **심층 크롤(브랜드 지정)** → 특정 브랜드를 대량(최대 3000개)·깊게(최대 2년) 즉시 크롤. "이 브랜드 제품이 다 안 나온다" 할 때 사용.

**확인 방법**:
1. 어드민 브랜드 수집 탭의 **수집 로그**(`collection_runs`)에 `kick_shop`/`shop_ingest` 성공 뜨는지.
2. `/products` 에서 개수·이미지 확인.
3. `/shop/<브랜드>` 에서 그 브랜드 제품 채워지는지.
4. 이미지 필드 직접 확인: `https://glovek.space/api/products?limit=5` → 응답에 `image` 값 있는지.

## 자주 막히는 지점 (트러블슈팅)

| 증상 | 원인 | 조치 |
|---|---|---|
| 상품이 아예 0 | `SHOP_ACTOR`/`SCRAPER_API_KEY` 미설정 | ② 재확인 후 Redeploy |
| 이미지만 계속 빈칸 | actor가 이미지 안 줌 | ①-3 다른 actor로 교체 or `SHOP_ACTOR_INPUT`에 이미지 옵션 |
| 특정 브랜드만 적음 | 브랜드당 상한/검색 매칭 | `SHOP_MAX_ITEMS`↑ + 어드민 **심층 크롤** |
| 브랜드 자체가 없음 | 영상 수집된 브랜드만 대상 | 어드민 심층 크롤로 브랜드 직접 등록(영상 없이도 시드됨) |
| 특정 국가만 없음 | `SHOP_COUNTRIES`에 없음 | 국가 추가 후 Redeploy |
| 수집이 안 늘어남 | 재시도 대기 | `SHOP_RETRY_DAYS`↓ |

---

## 한 줄 요약
**Apify에서 이미지 주는 틱톡샵 actor 하나 고르고 → Vercel에 `SCRAPER_API_KEY`·`SHOP_ACTOR`·국가/상한 넣고 Redeploy → 어드민에서 [틱톡샵 상품 수집] 누르면 끝.** 안 나오는 브랜드는 **심층 크롤**로 개별 보강.
