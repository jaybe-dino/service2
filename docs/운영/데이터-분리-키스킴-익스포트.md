# 데이터 분리 · 키 스킴 · 익스포트 (제품 / 크리에이터 / 매칭)

> 3개 엔터티로 완전 분리. 각각 **독립 key**와 **독립 CSV URL**. 따로따로 요청·다운로드 가능.
> 인증: `/admin` 로그인(브라우저) 또는 `?token=<CREATORS_EXPORT_TOKEN 또는 PARTNER_ADMIN_TOKEN>`(프로그램).

---

## 🔑 키 스킴 (관계도)

```
Product  ─┐
  key = product_id  ("US:1729606769780232427" = 국가 : 틱톡상품ID)
           │  raw_id = split(product_id, ":")[1]  = "1729606769780232427"
           │
           ├──< Product-Creator (매칭) >──┤
           │   복합 key = (product_id, handle)
           │   링크 조건: videos.product_ref == raw_id
           │
Creator  ─┘
  key = handle  (틱톡 유저명, 고유)
```

- **Product key** = `product_id` = `"<국가>:<틱톡상품ID>"`. 같은 상품이 국가별로 별개 행(US:123, TH:123).
- **Creator key** = `handle` (틱톡 @유저명). 국가 무관 고유.
- **매칭 key** = `(product_id, handle)` 복합. 영상의 `product_ref`(원시 상품ID)가 제품 raw_id와 일치하면 연결.

> 조인 규칙: `videos.product_ref = split_part(products.product_id, ':', 2)` → "이 제품을 태그한 영상 → 그 크리에이터".

---

## 1) 제품 (Product) — key: `product_id`

**URL**
```
/api/admin/products/export                 (전량)
/api/admin/products/export?country=US       (국가별)
/api/admin/products/export?brand=laka       (브랜드별)
```
**컬럼**
`product_id`(key) · country · brand · title · category · sub_category · price · currency · sold_count · **est_gmv** · commission_rate · image_url · url · collected_at

---

## 2) 크리에이터 (Creator) — key: `handle`

**URL**
```
/api/admin/creators/export                  (전량)
/api/admin/creators/export?missing=1        (이메일 없는 것만)
```
**컬럼**
`handle`(key) · profile_url · followers · videos · total_views · avg_views · verified · email · bio · brands · region · updated_at

---

## 3) 제품↔크리에이터 매칭 (Product-Creator) — key: `(product_id, handle)`

**URL**
```
/api/admin/product-creators/export                        (전량)
/api/admin/product-creators/export?country=US              (국가별)
/api/admin/product-creators/export?product=US:1729...       (특정 제품의 크리에이터)
/api/admin/product-creators/export?handle=someuser          (특정 크리에이터의 제품)
```
**컬럼**
`product_id`(key1) · `handle`(key2) · country · brand · videos · views · direct · **induced_gmv**

- **induced_gmv(유도 GMV)** = 제품 GMV × (이 크리에이터의 조회수 / 이 제품 태그 전체 조회수). 추정치.
- **direct** = 이 크리에이터가 그 제품을 **직접 태그**했는지(TRUE) vs 브랜드 연관.

---

## 매핑 예시 (3파일 조인)

```
products.csv          product_id = "US:1729..."
creators.csv          handle     = "medicube_us"
product-creators.csv  (product_id="US:1729...", handle="medicube_us", induced_gmv=128884392)
```
→ 매칭 파일의 `product_id`로 products.csv를, `handle`로 creators.csv를 각각 VLOOKUP/조인하면 완성.

---

## 공통

- 전량 기본(잘림 방지), `?limit=N`으로 축소.
- 응답 헤더 `X-Total-Count`에 총 행수(전량 확인용).
- 엑셀 한글 정상(BOM).
- 프로그램 접근: `?token=` (env `CREATORS_EXPORT_TOKEN` 또는 `PARTNER_ADMIN_TOKEN`).
