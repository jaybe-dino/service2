# Remake Studio — 품질 스펙: 유사도 · 완성도 · 디테일 (연결 전 기획/프로세스)

> 실제 영상 생성을 붙이기 **전에** 확립할 품질 기준과 파이프라인 게이트.
> 핵심 명제: **"구조는 닮되 복제하지 않고(유사도 제어), 제품 디테일은 정확히 살리며(디테일 충실도), 업로드 가능한 완성도(폴리시)로 낸다."**

---

## 0. 지금 카드가 그라데이션인 이유 (콘텐츠 미표시)
- 수집은 **성과 메타데이터만** 저장 → 원본 영상/썸네일 미보관(저작권 안전).
- 실제 미리보기 표시 옵션(연결 전 결정 필요):
  1. **TikTok oEmbed 썸네일** — 실제 미리보기(유사도 비교↑), 외부호출·레이트리밋 유의
  2. **원본 링크/임베드** — 원본 확인, 이탈·저작권 노출
  3. **플레이스홀더 유지** — 안전·빠름, 실제 모습 미표시
- 권장: **파일럿 단계에서 oEmbed 썸네일**을 붙여 사람이 "레퍼런스 vs 결과"를 눈으로 비교하게 하고, 운영에선 정책에 따라 선택.

## 1. 3대 품질 축 (정의 + 측정)

### 1-1. 유사도 (Similarity) — "구조 O, 표면 X"
저작권·오리지널리티 안전을 위해 **두 갈래로 분리 관리**한다.

| 구분 | 목표 | 무엇을 맞추나 / 다르게 하나 |
|---|---|---|
| **구조 유사도** | **70~85%** | 훅 타이밍(0~2s), 씬 순서·역할, 카메라 무빙, 페이싱, 톤 |
| **표면 유사도** | **< 30%** | 비주얼·카피·음원·색감·인물 → **반드시 브랜드화로 차별** |

- 측정(1차): **구조 체크리스트 매칭률**(아래 §3 필드 일치 개수 / 전체).
- 측정(2차, 로드맵): 프레임/임베딩 유사도로 표면 과유사 자동 경고.
- 게이트: 구조 <60% → "레퍼런스 반영 부족"(재생성), 표면 >40% → "과유사 위험"(카피/음원/색 변경).

### 1-2. 완성도 (Completeness / Polish)
업로드 가능한 상태인가. **QC 체크리스트 통과율**로 관리.
- 해상도/안정성(떨림·아티팩트 없음), 9:16, 요청 길이 충족
- **제품 정확도**(라벨·컬러·형태 일관), 자막 가독성, CTA 존재, 브랜드 컬러 반영
- **AIGC 라벨**(Omni Flash 자동 / 그 외 부착), 금지요소 없음(과장효능·저작권음원·실존인물)

### 1-3. 디테일 충실도 (Detail Fidelity) — 제네릭 방지
"뷰티 영상 같은 것"이 아니라 **이 제품의 이 훅**이어야 한다.
- 제품: 라벨 텍스트·컬러·용기 형태 **모든 컷 일관**
- 훅: 레퍼런스 훅을 **제품 맥락으로 리라이트**(제네릭 카피 금지)
- 씬: 각 컷에 **시간대·카메라·구체 동작·온스크린 텍스트** 필수
- 타이밍: 초 단위 비트(훅 2s, 결과 홀드 등) 유지

## 2. 파이프라인 게이트 (연결 전 확립)

```
① 레퍼런스 분해        → 구조 스펙 확정(훅·씬·카메라·톤·타이밍)
② 프롬프트화(디테일 주입) → 제품·훅·씬 필드 채움(AI 정교화 포함)
③ 생성(티어)          → draft 다량 → 예측 상위만 hd/premium
④ 자동 QC             → 실패/NSFW/워터마크/제품불일치 제외
⑤ 유사도·완성도 스코어링 → 구조≥60% / 표면≤40% / 완성도 체크 통과
⑥ 사람 검수           → 최종 승인 1명(레퍼런스 vs 결과 병렬 비교)
⑦ 승인 / 재생성 루프    → 미달 항목만 지정해 재생성(프리미엄 승급)
⑧ 업로드 + 성과 회수    → 실제 성과 → 예측·템플릿 고도화(플라이휠)
```

각 게이트 **정량 기준을 팀이 확정**해야 함(아래 §4 체크리스트).

## 3. 디테일을 살리는 구체 기법 (구현 연계)

| 목표 | 기법 | 현재/연계 |
|---|---|---|
| 제품 일관성 | 이미지 다각도 정규화 + **모든 씬 레퍼런스 컨디셔닝** + "라벨 텍스트 유지" 프롬프트 | 프롬프트 명시됨, 전처리(배경제거·정규화) 로드맵 |
| 훅 구체화 | 레퍼런스 훅 → **제품 맥락 리라이트**, 제네릭 금지 규칙 | AI 정교화(`/api/remake/prompt`)로 강화 |
| 씬 구체화 | time·role·camera·**action·onscreen-text** 필수 필드 | `buildRemakePrompt` scenes(+온스크린텍스트 보강 여지) |
| 유사도 제어 | 구조 프롬프트 강, **표면(음원/카피/색)은 브랜드화로 분리** | negative에 저작권/과유사 배제 명시 |
| 완성도 | 티어(프리미엄) · 업스케일 · 자막 번인 | 티어 구현됨 / 업스케일·자막 로드맵 |
| 검증 | 예측 게이트(Best-of-N) + 사람 QC | `predictViral` 구현, QC 프로세스 정의 |

> **보강 포인트(코드)**: 프롬프트 스키마에 **onscreen-text(자막 문구)** 와 **제품 라벨 보존 지시**를 필수화하면 디테일 충실도가 즉시 올라감. 요청 시 반영.

## 4. 연결 전 체크리스트 (사장님/팀 결정)

- [ ] **레퍼런스 미리보기 방식** 결정: oEmbed 썸네일 / 링크 / 플레이스홀더
- [ ] **골든 아웃풋 5개**: 파일럿 레퍼런스 5개 선정 + "이 정도면 통과" 기준 영상 합의
- [ ] **유사도 임계 확정**: 구조 하한(예 60%), 표면 상한(예 40%)
- [ ] **완성도 QC 체크리스트 확정**: 해상도·제품정확도·자막·CTA·AIGC라벨 항목/통과선
- [ ] **디테일 필수 필드 확정**: 씬별 온스크린 텍스트·타이밍·제품 라벨 보존 여부
- [ ] **검수 담당·재생성 정책**: 누가 승인, 몇 회까지 재생성, 언제 프리미엄 승급
- [ ] **KPI**: 예측↔실제 성과 상관, 검수 통과율, 편당 재생성 횟수(원가)

---

## 5. 우선순위 제안 (연결 전 → 후)
1. **레퍼런스 미리보기(oEmbed)** — 사람이 유사도/디테일을 눈으로 비교(가장 큰 체감)
2. **프롬프트 디테일 필수화**(온스크린텍스트·라벨보존) — 제네릭 방지
3. **유사도·완성도 스코어링 게이트**(구조 매칭률 자동 표시)
4. (연결 후) 업스케일·자막번인·멀티신 어셈블 — 완성도 상단
