# Glovek Remake Studio — 콘텐츠 BM · 실행 To-Do · 퀄리티 고도화 전략

> AI 레퍼런스 기반 제품 영상 자동 생성(`/remake`)을 **수익 모델 + 품질 우위**로 만드는 전략.
> 결론: **"싸게 많이"가 아니라 "터지는 퀄리티를 예측 가능하게"** — 이게 해자다.

---

## 1. 콘텐츠 BM (비즈니스 모델)

### 1-1. 과금 구조 — 크레딧 + 품질 티어
영상 생성은 원가(모델 $/초)가 실시간으로 나가므로 **크레딧 기반 사용량 과금**이 기본.

| 품질 티어 | 생성 모델(예) | 원가(대략) | 판매 크레딧 | 용도 |
|---|---|---|---|---|
| **Draft** | dop-turbo / Kling turbo | ~$0.2/클립 | 1 크레딧 | 컨셉 확인·다량 변형 |
| **HD** | Kling 2 / Higgsfield | ~$0.5/클립 | 3 크레딧 | 실제 업로드용 |
| **Premium** | Veo 3 / Gemini Omni Flash | ~$1/10초 | 6 크레딧 | 대표 캠페인·A컷 |

> 크레딧당 판매가는 원가 대비 마진(권장 3~5배)으로 책정. 애드온(업스케일·다국어 더빙·추가 변형)은 별도 크레딧.

### 1-2. 3개 판매 라인 (기존 트랙과 연결)
1. **셀프서브 (구독 번들)** — Live Focus/Onboarding 트랙에 **월 N 크레딧 무료 포함** → 초과분 크레딧 충전. (기존 몰 입점 구독과 결합, 이탈 방지)
2. **매니지드(대행)** — 우리가 **QC·편집·완성본까지 납품**. 고가·고마진. 브랜드는 검수만.
3. **성과 연동(옵션)** — 생성 영상이 만든 GMV의 일부를 기존 **판매 수수료 10%**에 얹어 회수. 브랜드 초기 리스크↓, 우리 업사이드↑.

### 1-3. 플라이휠 (장기 해자)
```
생성 → 브랜드가 틱톡 업로드 → 실제 성과(조회·전환)를 Glovek 대시보드로 회수
   → "어떤 구조·프롬프트가 진짜 터졌나" 학습 → 템플릿·예측모델 고도화 → 다음 생성 퀄↑
```
경쟁사는 "생성기"만 팔지만, 우리는 **실측 성과 데이터가 붙는 유일한 루프**를 가진다. 이게 가격이 아니라 품질로 이기는 방법.

## 2. 퀄리티 고도화 방식 (핵심)

> 단일 모델에 "잘 뽑아줘" 하는 게 아니라, **파이프라인으로 품질을 강제**한다.

### A. 모델 티어링 (draft → final) — 비용↓ 품질↑
- 초안은 **저렴·빠른 모델로 다량 변형** → 예측 점수/사람이 A컷 선정 → **선정본만 Premium 모델로 고품질 재생성**.
- 전량 Premium으로 뽑으면 비용 폭발. 티어링이 "퀄리티 대비 원가"의 핵심.

### B. Best-of-N + 예측 게이트
- 변형 N개 생성 → **바이럴 예측 점수 상위만 노출**. (지금은 `mockViralScore` 데모값 → **실측 예측모델로 교체** 필요: Higgsfield `virality_predictor` 또는 자체 학습)
- "많이 뽑고 걸러낸다"가 평균 품질을 올린다.

### C. QC 게이트 (자동 + 사람)
- **자동**: 실패/NSFW 자동 제외(이미 구현), 저작권 음원·실존인물·과장 효능 필터.
- **사람**: 업로드 전 **최종 승인 1명**. 매니지드 티어의 핵심 가치.

### D. 제품 일관성 컨디셔닝
- 업로드 이미지를 **모든 컷의 레퍼런스로 고정**(프롬프트에 이미 명시).
- 전처리 추가 시 향상: **배경 제거 → 다각도 정규화 → 라벨/컬러 고정**. (Higgsfield `remove_background` 등)

### E. 대화형 반복 편집 (Gemini Omni Flash 강점)
- "제품은 그대로, 조명/배경만 바꿔" 식으로 **재생성 없이 미세조정** → 브랜드 톤에 정확히 수렴. 재생성 비용·시간 절감.

### F. 후처리(업스케일 + 편집)
- 생성 클립 → **업스케일(2K/4K)** + 자막·CTA·브랜드컬러 합성(ffmpeg) + **AIGC 라벨/워터마크**.
- Omni Flash는 **SynthID·C2PA 내장** → 틱톡 AIGC 라벨 규정 자동 준수(컴플라이언스 = 품질의 일부).

### G. 프롬프트 정교화 루프 (이미 구현 + 강화)
- Claude 정교화(`/api/remake/prompt`) 적용됨. **레퍼런스 실측 성과가 높을수록 프롬프트 디테일을 더 강하게** 반영하는 규칙 추가 여지.

### H. 길이 한계 대응 (멀티신 어셈블)
- Omni Flash 10초·image2video 단일 클립 한계 → **여러 클립 생성 후 편집으로 15/30/60초 완성본** 조립. (로드맵)

**퀄리티 우선순위(비용 대비 효과順): B(예측 게이트) → A(티어링) → C(사람 QC) → D(제품 전처리) → F(후처리) → E/H(고급).**
