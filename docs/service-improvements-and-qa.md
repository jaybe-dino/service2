# Glovek 서비스 보강 목록 & QA 체크리스트 (브랜드사 관점)

> 작성 기준: 현재 구축된 기능/알려진 제약 반영. 개발 전 검토·논의용 문서.
> 우선순위: **P0** 신뢰·전환 직결 / **P1** 경험 개선 / **P2** 여유 시 개선

---

## 1) 서비스 보강 목록

### A. 입점·온보딩 경험
- **P0** 온보딩 자동 저장/이어하기 안정화 — 결제 후 이탈 → 재접속 시 "정보 입력" 단계로 정확히 복귀.
- **P0** 자가체크 결과 신뢰 근거 보강 — "왜 이 등급/트랙인지" 항목별 기여 설명.
- **P1** 파일 업로드 4MB 초과 대응(고해상 사업자등록증/제품사진 10MB+) — Vercel Blob 연동 검토.
- **P1** 온보딩 완료 후 다음 일정·담당자·D+Day 진행 현황을 마이페이지에서 상시 확인.
- **P2** 로그인 없이 자가체크 체험 → 결과 시점에 회원가입 유도.

### B. 요금·결제 신뢰
- **P0** 실결제 최종 점검(빌링키 발급/월 자동청구/6개월 합계결제/P013 해소) — 라이브 카드 테스트.
- **P0** 결제 영수증·세금계산서 발급(B2B 필수) — 현재 미제공.
- **P1** 결제 실패/연체 상태 안내 + 카드 재등록 UX.
- **P1** 6개월 약정 중도 해지 위약금(30%) 결제 전 명확화.

### C. 데이터·분석(핵심 가치)
- **P0** 수집 수치 투명성 — 고유 영상 수 vs 원본 수집 수 구분. 대량 수집 시 서버 페이지네이션(현재 12,000건 상한).
- **P1** 다국가 확장 준비 — 현재 US만. 확장 시 콘텐츠/인플루언서 국가 필터가 실제로 분화.
- **P1** 브랜드 리포트 PDF 다운로드(Advance) 실사용 검증 + 공유 링크.
- **P1** 인플루언서 제안 이후 진행 상태 추적(제안→검토→수락) 가시성.
- **P2** 저장 항목 비교/CSV 내보내기.

### D. 마이페이지·운영 관리
- **P1** 등록 제품 셀프 수정/인증서류 교체(현재 담당자 요청).
- **P1** 파트별 추가 결제(옵션 상품) 실제 구매 흐름 정의.
- **P2** 입고·번역·런칭 단계 알림/타임라인 대시보드.

### E. 신뢰·투명성·법무
- **P0** 매출/ROAS 예측치 고지 일관성(모든 노출 지점).
- **P1** 정산·물류비 단가표/정산서 샘플 자료 제공.
- **P1** 개인정보·데이터 수집 동의 문구 점검(파일 업로드·사업자 정보).

### F. 커뮤니케이션·지원
- **P1** 문의/제안 접수 확인 이메일(현재 자동메일 없음, 어드민 적재만).
- **P2** 인앱 채팅/카톡 상담 연결.

### G. 계정·보안·안정성
- **P0** SESSION_SECRET 환경변수 고정(세션 유지 안정성).
- **P1** 비밀번호 재설정 실메일 연동, 소셜 로그인 검토.
- **P2** 추천인 포털 2차 인증/링크 만료.

### H. 접근성·SEO·성능
- **P1** 홈 가로 캐러셀 접근성(키보드·스크린리더)·모바일 스와이프 안정성.
- **P2** QnA·요금·온보딩 구조화 데이터(AEO)·OG 이미지 점검.

## 2) QA 체크리스트 (브랜드사 시나리오)

### 1. 회원가입·로그인·세션
- [ ] 신규 가입 → Basic 로그인 유지, 새로고침 시 로그아웃 안 됨
- [ ] 추천인 코드(`?ref=`/직접입력) 가입 → 어드민/추천인 대시보드 반영
- [ ] 로그아웃/재로그인, 다중 탭 동기화
- [ ] 잘못된 비번/중복 이메일 에러 메시지

### 2. 요금제 열람(구분)
- [ ] `/plans`=플랫폼 구독만, `/plans/mall`=틱톡샵 입점만
- [ ] GNB "요금제" 호버 서브메뉴(플랫폼/입점) 이동
- [ ] 월간/연간 토글은 플랫폼에만 적용(입점 표엔 미적용 문구)

### 3. Pro 멤버십 결제
- [ ] `/checkout` → NICEpay(₩89,000) P013 없이 결제 완료
- [ ] 마이페이지 정기결제 상태·다음 결제일
- [ ] 정기결제 해지 → 상태 변경, 남은 기간 유지
- [ ] (익월) 자동청구 확인

### 4. 틱톡샵 입점 온보딩(핵심)
- [ ] 자가체크 3단계 페이징(판매경험→국가→인증), 국가 미선택 시 다음 차단
- [ ] 마지막 단계에서만 "예상 등급" 미리보기
- [ ] 결과가 별도 화면(큰 등급·스케일·추천트랙)으로 표시
- [ ] 트랙 선택: 추천 외 회색, Onboarding=가격 문의(문의 모달)
- [ ] Start/Live → 국가·약정 → 요금 실시간 계산 → 결제 → 정보입력 복귀
- [ ] 정보입력: 브랜드/제품/정산, 사업자등록증·제품 인증서류 업로드
- [ ] 제출 → 완료 화면(트랙·국가·등급·타임라인)
- [ ] 재진입 시 빈 폼 아닌 "신청 완료 현황"

### 5. 파일 업로드·다운로드
- [ ] PDF/JPG/PNG 4MB 이하 업로드 / 초과·타입 오류 메시지
- [ ] 본인/관리자만 다운로드(타인 접근 차단)

### 6. 마이페이지 관리
- [ ] 틱톡샵 입점 관리(트랙·국가·약정·결제내역·해지)
- [ ] 등록 제품 관리(목록·인증서류 다운로드)
- [ ] 결제완료·정보미입력 시 "이어서 완료"

### 7. 추천인
- [ ] 어드민 이름/아이디/비번 생성·비번 변경
- [ ] `/partner` 로그인 → 가입자·결제전환·예상 수수료(10/20/30%)
- [ ] 추천 링크 가입 귀속

### 8. 분석·필터
- [ ] Explorer 브랜드 속성 필터(제품카테고리/규모/포지셔닝/번들)
- [ ] 인플루언서 주력 국가 표기·필터
- [ ] 콘텐츠 0건 브랜드 숨김
- [ ] 매출/ROAS Advance/관리자만 노출

### 9. QnA
- [ ] `/tts/qna` 검색·필터·아코디언
- [ ] 심화 14문항, Q111(매출) 답변 없음→"미팅 시 안내"
- [ ] 요금/할인 수치 정책 일치(다국가 10/15/20%, 6개월 20%, Onboarding 가격문의)

### 10. 반응형·전면 캐러셀
- [ ] 홈 가로 슬라이드: PC 화살표·점 / 모바일 스와이프 / 3슬라이드
- [ ] 캐러셀 아래 스크롤 → 콘텐츠 섹션 자연 연결
- [ ] 모바일 온보딩 결과·트랙 카드 깨짐 없음
- [ ] 로고 클릭 → 메인(/)

### 11. 엣지케이스·에러
- [ ] DB/결제 미설정 환경 안내(크래시 없음)
- [ ] 결제 취소/실패 상태·재시도
- [ ] 자가체크 중 새로고침/뒤로가기 복원
- [ ] 블락된 인플루언서/브랜드/영상 노출 차단
