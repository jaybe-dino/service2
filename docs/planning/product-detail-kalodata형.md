# 제품 상세 고도화 (kalodata product/detail형) — 기획 · 개발 준비

> 목표: 제품 단위로 **매출 추이 + 크리에이터(연결 매출) + 영상 성과 + 가격/커미션**을 한 화면에.
> 참고: kalodata.com/product/detail — 제품별 GMV·판매 추이·연결 크리에이터·영상 랭킹.
> 기준: 현행 `/product/[id]` 위에서 증분. 이미 있는 것/추가할 것 구분.

---

## 1. 현재 상태 (As-Is) — `/product/[id]`, `/api/products/[id]`
✅ 이미 구현됨:
- 제품 지표(가격·판매량·추정 GMV·커미션) + 리메이크 CTA
- **판매 추이** 스파크라인(product_snapshots 최근 30일, 성장률)
- **관련 크리에이터**(직접 태그 우선 → 브랜드 폴백) + **크리에이터 영상 리스팅**
- 매칭 모드(direct/brand) 표기

한계(= kalodata 대비 갭):
- 추이가 스파크라인(판매수)뿐 — **일별 GMV·판매량 이중축 차트**, 기간 선택(7/30/90일) 없음
- 크리에이터가 "관련"까지만 — **크리에이터별 연결 매출(이 제품 유도 GMV)·영상수·조회수 기여** 랭킹 없음
- 영상 성과 랭킹(조회/급상승)·가격 이력·리뷰/재고 등 부재
- 제품 카테고리·순위(카테고리 내 랭크) 없음

---

## 2. 목표 화면 구성 (To-Be)
1. **헤더**: 제품명·브랜드·썸네일(있으면)·가격·통화·국가 · [TikTok Shop 보기]·[리메이크]
2. **KPI 스트립**: 추정 GMV · 판매량 · 커미션 · 평균 단가 · **일 판매 증감(급상승)** · 카테고리 내 순위
3. **매출/판매 추이 차트**: 일별 GMV + 판매량 이중축, 기간 7/30/90일 토글 (product_snapshots)
4. **가격 추이**: 스냅샷 price 변화(할인 이벤트 감지)
5. **연결 크리에이터(핵심)**: 이 제품을 태그한 크리에이터 랭킹 — 영상수·총조회·**유도 GMV(이 제품)**·적합도 → `/creator/[handle]` 연결 + "아웃리치 추가"
6. **영상 성과**: 이 제품 관련 영상 랭킹(조회/급상승/참여) + 배지(광고/샵/직접태그)
7. **동일 카테고리 제품**: 같은 카테고리 상위 제품(대체/경쟁)

---

## 3. 데이터 — 있는 것 / 필요한 것
- **product_snapshots**(product_id, snap_date, sold_count, price, est_gmv) — ✅ 이미 적재. 차트·가격추이·급상승의 원천.
- **videos.product_ref** ↔ products(prefix 제거) — ✅ 직접 태그 매칭. 크리에이터 연결·유도 GMV·영상 성과의 원천.
- 카테고리: classifyProduct(title) — ✅ 존재(제품 랭킹에서 사용). 카테고리 내 순위/동일 카테고리에 재사용.
- 썸네일: 현재 미수집(products에 image 컬럼 없음) → **선택**: 수집 매핑에 image_url 추가(있으면), 없으면 브랜드 컬러 플레이스홀더.

추가 컬럼(선택): `products.image_url text`, `products.category text`(현재 read 시 분류 → 저장하면 순위 쿼리 가속).

---

## 4. 개발 준비 (API/화면)
### 4-1. `/api/products/[id]` 확장
- `trend`: 기간 파라미터(`?period=7|30|90`) → 일별 `{date, sold, gmv, price}` 배열(현재 30일 고정 → 유연화)
- `priceSeries`: 스냅샷 price 배열
- `creators`: 이 제품 유도 GMV 순 — `{handle, videos, views, inducedGmvForThisProduct, direct, fit}` (product_ref = 이 제품 raw id로 필터)
- `topVideos`: 이 제품 관련 영상 성과순(이미 relatedVideos 있음 → 정렬·급상승 추가)
- `rankInCategory`: classify로 카테고리 산출 → 그 카테고리 GMV 순위
- `similar`: 동일 카테고리 상위 N개 제품

### 4-2. `/product/[id]` 화면
- 스파크라인 → **이중축 차트 컴포넌트**(GMV 막대 + 판매 선, 기간 토글) — SVG 자체 구현(외부 차트 라이브러리 CSP/의존 회피)
- 연결 크리에이터 랭킹 테이블(+적합도·"아웃리치 추가" 버튼 → 아웃리치 P1과 연결)
- 영상 성과 랭킹(정렬 토글)
- 동일 카테고리 제품 카드

### 4-3. 아웃리치 연계
연결 크리에이터에서 바로 **"아웃리치 추가"** → 아웃리치 파이프라인(P1)로 대상 등록. 제품↔크리에이터↔아웃리치가 한 흐름.

---

## 5. 로드맵
- **P0(차트·연결 크리에이터 강화, 외부의존 0)**: 이중축 추이 차트(기간), 연결 크리에이터 유도 GMV 랭킹, 영상 성과 랭킹, 카테고리 순위 — **현 데이터로 즉시 가능**
- **P1**: 가격추이·동일 카테고리 제품·썸네일(수집 매핑에 image_url 추가 시)
- **P2**: 리뷰/재고/셀러 등 심화(별도 수집 필요)

---

## 6. 즉시 실행 제안 (제품 상세 P0)
① `/api/products/[id]`에 period·priceSeries·이 제품 유도 GMV 크리에이터·카테고리 순위 추가 → ② `/product/[id]`에 이중축 차트 + 연결 크리에이터 랭킹 + 영상 성과 랭킹.
→ kalodata product/detail의 핵심(제품+크리에이터+추이)이 현 데이터만으로 완성.
