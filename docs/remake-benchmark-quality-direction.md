# Remake Studio — 경쟁 벤치마크 & 퀄리티 향상 방향

> 목적: AI 제품/UGC 광고영상 선도 서비스들이 "무엇으로 퀄리티를 내는지" 분석하고,
> GloveK Remake Studio가 그중 무엇을 흡수해 퀄을 올릴지 우선순위를 정한다.
> ⚠️ 실시간 웹검색 실패로 아래는 도메인 지식(2026-01 기준) 정리 — 최신 가격/기능은 교차확인 권장.

## A. 벤치마크 — 누가 무엇으로 퀄리티를 내나

| 서비스 | 핵심 강점(퀄리티 레버) | 우리에게 주는 시사점 |
|---|---|---|
| **Arcads** | **실사급 AI UGC 배우**(실제 배우 라이선스 기반) + 감정 연기 + 훅 변형 | UGC 광고 전환의 1순위 = "사람이 말하는 것처럼" |
| **Creatify** | 제품 URL→UGC 광고, AI 아바타, **배치 변형**, AI 스크립트 | URL 자동추출·대량 변형·스크립트 엔진 |
| **Captions (Mirage/AI Ads)** | **워드 단위 자막** + 립싱크 + AI 편집(컷·비롤) | 편집 폴리시(자막·리듬)가 완성도를 만든다 |
| **HeyGen** | 아바타 + **음성 클론 + 다국어 립싱크 더빙** | 다국어 진출(우리 4개국)엔 립싱크 더빙이 핵심 |
| **Pippit / CapCut (ByteDance)** | 제품→영상, 아바타, **틱톡 네이티브 자동편집** | 틱톡 톤·자동편집·샵 연동 |
| **TikTok Symphony** | 틱톡 공식 AI: 아바타·스크립트·제품→영상, **틱톡샵/광고 직결 + AIGC 라벨 내장** | 틱톡샵 입점 서비스라면 반드시 검토(연동/컴플라이언스) |
| **Flair.ai / Pebblely / Booth.ai** | **AI 제품 포토그래피**(배경·씬·제품 일관) | 영상 전 "제품 비주얼 정확도" 전처리 |
| **Veo3 / Kling / Runway / Omni Flash** | 생성 모델 자체 화질·모션 | 벤더 라우팅으로 최적 모델 선택(구현됨) |

## B. 퀄리티를 만드는 6대 공통 요인 (선도사 공통분모)

1. **실사 UGC 프레젠터 + 립싱크** — "사람이 제품 말하는" 형식이 전환을 만든다(가장 큰 갭).
2. **편집 폴리시** — 워드 단위 자막·음악 싱크·전환·리듬. 생성만으론 완성도 부족.
3. **제품 비주얼 정확도** — 배경제거·다각도 정규화로 모든 컷 제품 일관.
4. **스크립트/훅 엔진 + 다국어 보이스** — 성과 데이터 기반 훅 + TTS/더빙.
5. **브랜드 킷** — 폰트·컬러·로고·톤 고정으로 브랜드 일관성.
6. **배치 + A/B + 성과 피드백** — 많이 뽑고, 테스트하고, 학습.

> 컴플라이언스도 품질의 일부: **AIGC 라벨(SynthID/C2PA)**, 틱톡샵/광고 정책 준수.

## C. GloveK 위치 — 강점 & 갭

**우리만의 강점(해자):**
- **성과 피드백 플라이휠** — 실제 틱톡 성과가 대시보드로 회수 → 예측·템플릿 고도화. 대부분 경쟁사엔 없음.
- **레퍼런스 구조 리메이크** — "터진 구조"를 골라 장면별 1:1 재현(구현됨).
- **틱톡샵 입점 번들** — 생성이 입점/운영 트랙과 결합.

**퀄리티 갭(선도사 대비 부족):**
1. ❌ **UGC 프레젠터/립싱크 없음** — 지금은 제품 모션 클립만. (최대 갭)
2. ❌ **편집 폴리시 없음** — 자막·음악·전환·완성본 어셈블 미비.
3. △ **제품 전처리 약함** — 배경제거·정규화 미적용.
4. △ **다국어는 자막만** — 보이스/립싱크 더빙 없음.
5. ❌ **브랜드 킷 없음** — 브랜드 컬러 1개만.

## D. 퀄리티 향상 로드맵 (우선순위 = 전환 영향 × 실현성)

### 🥇 1순위 — UGC 프레젠터 + 립싱크 (가장 큰 전환 레버)
- "AI 인물이 훅을 말하며 제품 소개" 포맷 추가. 립싱크 + 감정.
- 방식: ①Omni Flash/HeyGen형 아바타 ②Higgsfield speech2video ③틱톡 Symphony 아바타 연동.
- 컴플라이언스: 실존 인물 유사성 차단 유지.

### 🥈 2순위 — 편집 폴리시(완성본 어셈블)
- **워드 단위 자막**(브랜드 컬러) + 음악 싱크 + 전환 + 씬 클립 이어붙이기(멀티신 어셈블).
- ffmpeg/편집 백엔드 필요(서버리스 밖 워커) — 완성도 상단을 올림.

### 🥉 3순위 — 제품 비주얼 전처리
- 업로드 이미지 **배경제거 → 다각도 정규화 → 라벨/컬러 고정** 후 생성.
- Higgsfield remove_background 등 연동.

### 4순위 — 다국어 보이스/더빙
- 훅·VO를 4개국 TTS(ElevenLabs 등) + 립싱크 더빙.

### 5순위 — 브랜드 킷
- 브랜드별 폰트·팔레트·로고·톤 저장 → 모든 생성에 자동 적용.

### 상시 — 성과 플라이휠 강화(해자 심화)
- 실측 성과 회수 → 예측모델·훅 라이브러리·템플릿 자동 업데이트. **여기에 계속 투자.**

## E. 실행 제안 (즉시 → 중기)

| 시점 | 액션 |
|---|---|
| 즉시(코드) | 제품 전처리(배경제거) 훅 · 브랜드 킷 필드(폰트/로고) · 씬 릴 정리 |
| 파일럿 | UGC 프레젠터 1개 벤더 연동(립싱크) — 전환 A/B |
| 중기(별도 워커) | 편집 폴리시(자막·음악·멀티신 어셈블 완성본) |
| 전략 | **TikTok Symphony 연동성 검토**(틱톡샵 직결·AIGC 라벨) |

> 결론: 경쟁사가 "생성 화질"로 경쟁할 때, GloveK는 **①UGC 프레젠터(전환) + ②편집 폴리시(완성도) + ③성과 플라이휠(해자)** 3층으로 간다.
> 특히 성과 플라이휠은 흉내내기 어려운 우리만의 퀄리티 우위 — 생성 품질을 "데이터로 계속 좋아지게" 만든다.
