# K-Trend Analytics

**110개 이상의 K-뷰티 브랜드가 글로벌 틱톡에서 만들어내는 바이럴 콘텐츠와 어필리에이트 성과를 한 화면에서 탐색하는 콘텐츠 중심 B2B 분석 SaaS.**

복잡한 대시보드 대신, 로그인하자마자 실제 해외 틱톡에서 바이럴 중인 한국 코스메틱
브랜드의 콘텐츠를 매소너리 그리드로 탐색하는 "콘텐츠 탐색 중심 인터페이스"를 제공합니다.

## 핵심 화면

| 경로 | 화면 | 설명 |
| --- | --- | --- |
| `/` | 🎬 틱톡 콘텐츠 탐색기 | 좌측 110+ 브랜드 A–Z 필터 사이드바 + 다차원 실시간 필터(카테고리·국가·스타일·인플루언서 규모) + 임베디드 틱톡 플레이어 카드 매소너리 그리드. 카드 하단에 수수료율·기여매출·ROAS·CPM 어필리에이트 지표 노출. |
| `/influencers` | 👤 인플루언서 DB | 검증된 틱톡 샵 어필리에이트 크리에이터 목록. 진정성 지수·평균 성과 제공. Pro 미구독 시 단가·컨택 라인 블러(잠금) 처리. |
| `/reports` | 📈 브랜드 성장 리포트 | 브랜드별 조회수·어필리에이트 매출·협업 수·경쟁사 SOV(Share of Voice) 비교 리포트. |
| `/viral` | ⚡ 실시간 바이럴 감지 | 매주 월·목 09:00 정기 스캔으로 이상 급증/신규 바이럴을 감지하고 대응 전략(CTA) 제안. |
| `/plans` | 💎 요금제 | Basic(무료) / Pro($159) / Enterprise($399~) + Add-on + 틱톡 샵 연동 20% 할인. |

## 타겟 국가 (6개국)

미국 🇺🇸 · 태국 🇹🇭 · 베트남 🇻🇳 · 필리핀 🇵🇭 · 말레이시아 🇲🇾 · 싱가포르 🇸🇬
— K-뷰티 틱톡 샵 매출이 가장 활발한 서구권 1개국 + 동남아 5개국.

## 기술 스택

- **Next.js 16** (App Router, Turbopack) · **React 19** · **TypeScript**
- **Tailwind CSS v4** · **lucide-react** 아이콘
- 콘텐츠/브랜드/인플루언서 시드 데이터는 결정적(seeded) 생성기로 구성 — SSR/CSR 일관성 보장.

데이터 모델은 `src/data/ktrend/`, 화면 컴포넌트는 `src/components/ktrend/`에 위치합니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:3000)
npm run build    # 프로덕션 빌드 (타입체크 포함)
npm run start    # 프로덕션 서버
```

> 어필리에이트 지표(기여 매출·ROAS·CPM 등)는 데모용 추정치이며 실제 매출과 차이가 있을 수 있습니다.
> 틱톡 샵 판매자 계정(OAuth2) 연동 시 실매출 피드백 루프로 추정 정확도를 고도화하는 것이 로드맵입니다.
